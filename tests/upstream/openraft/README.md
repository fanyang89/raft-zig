# OpenRaft

- Repository: <https://github.com/databendlabs/openraft>
- Revision: `0d15d99844e8245ac917ce76ce2e4598665d0e40`
- License: MIT OR Apache-2.0

OpenRaft contributes independently implemented stateful safety invariants and
behavioral scenarios that are not duplicates of the etcd/raft baseline.

The inventory contains 286 scoped cases, including 22 turmoil invariant cases;
runtime helpers are not inventory entries. The upstream dual-license texts are
preserved in `LICENSE-APACHE.upstream` and `LICENSE-MIT.upstream`.
